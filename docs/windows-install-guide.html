How long? About 3–4 hours on site: 1 hour for the PC, printer and Faida, 1 hour for settings and tests, the rest for stock and training. Plan it on a quiet morning, never during opening hours.

1. Before you go at the office

Put on a USB stick

Bring

  • A second USB drive, 16 GB or more, that stays at the bar for the nightly backups.
  • A spare roll of 80 mm thermal paper, and a USB cable for the printer.
  • Printed: the staff guide, the house rules (one per staff member to sign), the handover checklist, and this guide.
  • An envelope to seal the backup passphrase and (if used) the disk recovery key in, for the owner.

Ask the owner to have ready

  • Every staff member's name and role (owner, supervisor, waiter). Each person types their own PIN, so they need to be there.
  • Tables and their names (optional: Faida also works with order numbers only), tot size in ml, the time the business day ends (normally 06:00).
  • Credit customers with their phone numbers and credit limits.
  • An hour of her time for the opening stock count, and to sign at the end.
Decide the backup passphrase before you go. It is a long phrase (e.g. four unrelated words). Without it no backup can ever be opened. Keep it in Avinaya's password manager, and seal a copy for the owner. Never leave it on the PC.

2. Check and prepare the PC ≈ 20 min

  1. Windows version. Press Win+Pause (or Settings > System > About). It must say 64-bit operating system. Note the edition (Home or Pro) on the record sheet.
  2. Disk space. At least 10 GB free on C: (File Explorer > This PC).
  3. Date, time and time zone. Settings > Time & Language: time zone (UTC+03:00) Nairobi, and the clock correct to the minute. Faida uses this clock for every sale and the business day.
  4. The counter account. Decide which Windows account the counter runs in (e.g. counter). Sign in to that account and make sure it is an administrator while you install (Settings > Accounts > Family & other users). The installer sets up the full-screen counter for the account that runs it.
  5. Never sleep. Settings > System > Power & sleep: Screen and Sleep both Never (on mains power).
  6. Windows Update. Settings > Update & Security > Change active hours: cover the bar's opening hours (e.g. 10:00 to 04:00 as far as Windows allows) so it never restarts during service.
  7. Remove clutter. With 4 GB of memory, the PC should run nothing else: uninstall trial software and games, and turn off apps that start with Windows (Task Manager > Start-up).
  8. Disk encryption. Windows 10 Pro: turn on BitLocker (Control Panel > BitLocker Drive Encryption) and put the recovery key in the sealed envelope, not on the PC. Windows 10 Home has no BitLocker: check Settings > Update & Security > Device encryption; if it isn't there either, write "no disk encryption" on the record sheet and tell the owner.
  9. Browser. Open Microsoft Edge. If it is the new Edge (blue-green wave icon) it is fine. If Edge is missing or very old, install Chrome from the offline installer you brought. Faida uses Chrome if it is installed, otherwise Edge.
  10. UPS. The PC (and the router, if any) on the UPS.
Windows 10 no longer receives security updates (support ended October 2025). Tell the owner; if the Lenovo can take Windows 11, that upgrade is worth doing later. Until then, this PC is for Faida only: no web browsing, no email, no USB sticks from customers.

3. Set up the printer in Windows ≈ 20 min

Faida prints by sending the printer's own language (ESC/POS) to a Windows printer shared as POS80.

  1. Load the 80 mm paper, plug the Xprinter into the mains and into a USB port on the PC itself (not a hub), and switch it on.
  2. If a cash drawer is used, plug its cable (RJ11, like a phone plug) into the DK / Cash drawer port on the back of the printer.
  3. Install the Xprinter driver from your USB stick and choose the XP-Q851L / 80 mm model when asked. If no driver will install: Control Panel > Devices and Printers > Add a printer > "The printer that I want isn't listed" > Add a local printer > port USB001 > manufacturer Generic, printer Generic / Text Only. Faida sends its own formatting, so this works too.
  4. Control Panel > Devices and Printers: right-click the printer > Printer properties > Print Test Page. A page must come out.
  5. In the same window, tab Sharing: tick Share this printer and set the Share name to exactly POS80. Click OK.
  6. Control Panel > Network and Sharing Center > Change advanced sharing settings > Private: Turn on file and printer sharing. Save.
  7. Check the share: press Win+R, type \\localhost, Enter. A window must show POS80.

4. Run FaidaSetup.exe ≈ 20 min

  1. Copy FaidaSetup-0.3.1.exe to the Desktop.
  2. Optional, recommended: check the file arrived whole. In PowerShell: certutil -hashfile $HOME\Desktop\FaidaSetup-0.3.1.exe SHA256. The long number must match the one in the .sha256 file.
  3. Right-click the file > Run as administrator > Yes.
  4. If a blue window says "Windows protected your PC": click More info > Run anyway. (The installer is not signed with a paid certificate; this is expected.)
  5. Read the welcome page and click Install. It unpacks for about a minute.
  6. It asks: "Will the owner use the phone view through the Faida cloud?" For Chewaz, answer No (counter only), unless the owner has changed her mind today.
  7. A console window (dark, with text) opens and asks the questions below. Type the answer and press Enter. Passwords and PINs don't show while you type; that is normal.

5. Sign-in, restart and full screen ≈ 10 min

  1. Automatic sign-in for the counter account: press Win+R, type netplwiz, Enter. Select the counter account, untick "Users must enter a user name and password", OK, and type its password twice. If the tick box is missing: Settings > Accounts > Sign-in options, turn off "Require Windows Hello sign-in", then try again.
  2. Restart the PC. It must come back straight into the Faida PIN screen, full-screen, with no desktop showing. Give it up to two minutes after Windows starts.
  3. Type the owner's PIN with the keyboard and press Enter. The owner lands on her Dashboard. The top bar must show Counter only and Printers OK.
Getting to the desktop (technician only). The counter re-opens by itself if it is closed. To work in Windows: press Ctrl+Shift+Esc for Task Manager > File > Run new task > taskschd.msc > OK. In Task Scheduler Library, right-click Faida kiosk > End, then close the browser with Alt+F4. Never end Faida counter: that is Faida itself. A restart brings everything back.

8. Backups to the USB drive ≈ 10 min

  1. Plug the backup USB drive (16 GB+) into the PC. In File Explorer, right-click it > Rename > FAIDABACKUP (exactly this name).
  2. Make one backup now. Open PowerShell as administrator and type: Start-ScheduledTask "Faida backup"
  3. After a minute, the drive has a folder faida with a file faida-local-….fbk.
  4. In Faida, the owner's Dashboard > Needs a look must not show a red backup line. (Before the first backup it says "No backup has been made yet".)
  5. The drive stays plugged in. Faida backs up every night at 04:30, or when the PC next starts if it was off. It keeps the 14 newest backups.
  6. Seal the passphrase in the envelope and give it to the owner.
Counter only means the red line is the only warning. Show the owner: if the Dashboard ever says a backup failed or none was made, check the USB drive is plugged in, or call support. Advise her to take a copy of the drive's faida folder home once a week, so a theft or fire at the bar can't take everything.

9. Opening stock ≈ 1 hour

  1. Owner area > Stock: check every stock item has the right unit (bottles, or ml for spirits sold by the tot), buying price and reorder level. Set up recipes for dishes if the owner wants kitchen stock.
  2. Print a blank Count sheet (button at the top of the Stock page).
  3. Count with the owner: sealed bottles, and the open bottle in tenths. Enter it in Stock take.
  4. Tell her the first week is calibration: small differences are normal while everyone learns.

10. Train the staff 15–30 min each

Waiters

  • Log in: type the PIN on the keyboard and press Enter (or click the keys). Never share the PIN.
  • Click items, then the big SEND & PRINT. Nothing is poured or cooked without a slip.
  • PAY: cash (type what the customer gave; the change shows big), or M-Pesa (type the last 4 characters from the customer's message, Enter).
  • Kitchen tickets print at the counter: take them to the kitchen straight away.
  • LOG OUT when walking away. The screen also locks by itself.
  • End my shift: count the cash with the owner or supervisor, agree with the PIN; two slips print.

Supervisor and owner

  • Approvals: type your own PIN on the waiter's screen for removals, discounts and free items.
  • Owner area: receiving cash at hand-over, floats, pay-outs, credit, stock, Daily closing (CLOSE DAY after the last shift), reports, Excel export, Print / PDF, and the Audit log (who did what).
  • The support number is at the bottom of the Owner area menu and on the PIN screen.

Give each person the printed staff guide, and have each sign the house rules.

11. Soft launch and handover

  1. Soft launch: 2–3 days using Faida alongside the bar's current method. Compare the totals each night.
  2. Visit or call at the end of each day: check the backup line on the Dashboard, the printer log, and any questions.
  3. When the owner is happy, go through docs/handover-checklist.md with her. Items 14 and 15 have a counter only version. When every line works, she signs, and the second payment is due.
  4. Save the support number +254 797 033 513 on her phone. The 3-month support period starts on that date.

13. Updating later

  • Avinaya brings a new FaidaSetup-<version>.exe on a USB stick. No internet is needed.
  • Run it after closing, with every shift ended and every bill paid; it refuses otherwise.
  • It takes a backup first, installs the new version beside the old one, and checks it. If anything fails it goes back to the old version by itself; nothing is lost.
  • Settings, the database, pictures and backups are never touched by an update.
